What I learned

Describe your design: why these routers, LANs and links, and how you chose the addresses.

There are 4 router joining together to form a square which ensure each router has at least two ways to reach each other. The address is simple, 10.XX.[Host Number].0/24 for each of the LAN, then for the link it is 10.XX.[router number][router number].0/30.

Which route summarises several LANs? Which networks does it cover, why is it correct, and what else would it attract if you added a network inside its range?

10.99.2.0/23 which cover 10.99.2.0/24 and 10.99.3.0/24 as they share the same first 23 bits, if new network within the range join, then it will get routed as well.

When you took a link down, what happened, and why couldn't your routes recover even though another path existed? What would have recovered?

It cannot recover because the route is static and there is no another static route specify another path, it would have been recover if dynamic routing protocol like ospf or IS-IS is used.

In your network, what was the control plane? Who worked out the routes, and what does that mean for a network of 40 routers?

The control plan is the route info in the yaml file, the python script is the one pushing the route into the routers, with the script. pushing into 40 routers would be easy and can avoid human error.
